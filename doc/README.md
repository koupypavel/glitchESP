# Reference material

- `ESP32-P4-WIFI6-Touch-LCD-5-Schematic.pdf` — board schematic, from Waveshare's repository
  (see `THIRD_PARTY_NOTICES.md`).
- ESP32-P4 datasheet — not stored here. Download it from Espressif:
  https://www.espressif.com/sites/default/files/documentation/esp32-p4_datasheet_en.pdf
  (a local copy named `esp32-p4_datasheet_en.pdf` in this folder is ignored by git).
- Board wiki: https://docs.waveshare.com/ESP32-P4-WIFI6-Touch-LCD-5
- `examples_esp32p4.zip` / `examples_unzipped/` — Waveshare's example repository, not committed
  (230 MB). Get it from https://github.com/waveshareteam/ESP32-P4-WIFI6-Touch-LCD-5 and unzip
  into `examples_unzipped/` if you need the stock examples (the `m0/` folder holds the two we
  used for the hardware check).
